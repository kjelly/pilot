### A: special-character admin password (the review's scenario)

This ran last on A, after every other A check. It reproduces the scenario from the review: re-running `freeipa-server-replica-apply.yml` on an existing DNS replica with the single-host vm-target inventory, which has no `freeipa-server` group.
