## Not covered / deviations

- The run was on the local host, not a vm-target. Database compatibility depends on the binaries, not on the deployment.
- No queued `webhook_outbox` row crossed versions. Only deploy/reconcile workflows enqueue, and `send-test` deliberately does not. The outbox open/claim/flush path did run in every phase.
- Detection Engine opened no signal episodes, because the fake data was steady. The episode tables stayed empty in every phase.
- The first attempt of this run failed for harness reasons, not product reasons, and the run above was repeated from empty directories:
  - session-store could not bind its read socket, because the scratch path exceeded the 108-byte `sun_path` limit;
  - Detection Engine classified the fake samples as `future_sample`, because the fake stamped wall-clock time instead of the query's `time`.
