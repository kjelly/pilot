# freeipa-dns-client: C7 checks the timeout glibc uses — 2026-10-02

Candidate `6224982` fixes the C7 command in `docs/verification/freeipa-dns-client.md` (PR #37 review). The previous C7 only checked that an `options` line contained `timeout:1` and `attempts:2`. glibc applies options in file order and keeps the last value, so `options timeout:1 attempts:2 timeout:10 attempts:5`, or a later `options timeout:10` line, passed C7 while glibc waited 10 seconds per nameserver. The new C7 parses `/etc/resolv.conf` the way glibc's `res_setoptions()` does and compares the effective values. The playbooks are unchanged, so this record repeats the runs that read C7 and adds drift cases that must fail.
