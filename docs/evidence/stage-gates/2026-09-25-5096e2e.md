# Stage gates under tag-scoped runs; missing cross-checks (2026-09-25)

Covers candidate `5096e2e` on top of `main` `8bcf204`.
- Six apply playbooks (core-infra-provider, docker, keycloak, keycloak-db, reverse-proxy, seaweedfs-s3) had untagged stage gates, so `--tags <row>` skipped them while the row's tasks ran. `pilot deploy`'s single-component wizard passes its "只跑某幾個檢查項目" answer straight to `--tags`, so a host in the `prod` group deployed at the default stage (sandbox) with a row tag skipped the environment-group cross-check and was changed with no confirmation. The 18 stage gates are now `always`.
- freeipa-ca-trust, internal-endpoint (both plays) and reverse-proxy had no cross-check; it is added. In internal-endpoint it is skipped only when the run's sole tag is `iep_decommission_verify`, the host-decommission provider's read-only query, which passes no stage and runs over the whole server inventory.

No spec row changes.
