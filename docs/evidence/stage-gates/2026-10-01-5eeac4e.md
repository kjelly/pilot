## Found, not fixed here

Rescue/rollback tasks in seven of these playbooks (alertmanager, dashboard, prometheus, restic-backup, thanos-query, detection-engine, pam-oidc-sshd) are untagged too. Checked locally on ansible-core 2.19.2: under `--tags C3`, a failing C3 step runs only `always`-tagged rescue tasks. A failed tag-scoped run therefore does not roll back. This is left for a separate change, which also has to make each rescue's snapshot prerequisites run.
