## Result in one paragraph

Everything the runbook requires passed on this candidate **except the first site-wide apply**: on its first attempt the
site-wide `site.yml` deploy failed on the two AlmaLinux hosts (`freeipa-server`, `freeipa-replica`) at the `wazuh-fim` role,
Step 11a (finding H1). The identical wizard run again on the same VMs passed `failed=0`, and every later step, spec and
runbook check passed. The run is therefore **not a single-pass from-zero PASS**: it is a from-zero run with one failed first
apply and one same-VM retry, and the table below says which is which. The AG06 row-tag arms, the fact-cache behavior, the
agent-controller/detection-engine procedure text and all fixture-bound classifications are reported separately below.
