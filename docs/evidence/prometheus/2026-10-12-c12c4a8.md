## 5. Real bug found in the first candidate

`e2b75f8` read the container's files with `ansible.builtin.stat` on
`/proc/<pid>/root/<path>`. `readlink /proc/<pid>/root` is `/`, and the stat
module failed with `[Errno 2] No such file or directory:
b'/etc/prometheus/prometheus.yml'` — it looked for the container path on
the host. The apply failed and the rescue ran. `c12c4a8` hashes the
container side with `sha256sum -- /proc/<pid>/root/<path>` (real output
`<hex>  <path>`, rc=1 and `No such file or directory` on stderr for a
missing file) and compares it with the host file's sha256 from `stat`.
