## 5. Real bugs found and fixed on this round

**Bug 1 — fixture's nginx couldn't read its own htpasswd file.** The
Basic-Auth credential file was first written `owner: root, group: root, mode:
0640`; nginx's worker process runs as `www-data`, which has no access, so
authenticated requests to `:9400/metrics` returned `500` (`open() ... failed
(13: Permission denied)` in `nginx/error.log`). Fixed to mode `0644` (the
content is a salted MD5-crypt hash, not the plaintext password — same
world-readable trade-off already used elsewhere in this repo for
non-root-uid-consumed secrets).

**Bug 2 — `docs/verification/prometheus.md` C15's `pilot_host` check was not
job-scoped.** The pre-existing Command was a bare, file-wide `grep -qE
"^[[:space:]]*pilot_host:"`. Once a second auto-discovery block (dcgm-exporter)
could also render a `pilot_host` line, this spuriously **passed** C15 even in
a scenario where node-exporter itself rendered no scrape job at all (zero
`host-monitoring` hosts) — the grep was matching the *other* job's label.
Verified broken via `pilot verify --probe` against the real running instance,
then fixed (and re-verified via the same `--probe` mechanism, and end-to-end
via §4 above) to an `awk` script that scopes the match to each job's own
`job_name: node` / `job_name: dcgm` block. C18 (dcgm-exporter's own equivalent
row, new in this round) was written with the scoped form from the start.
