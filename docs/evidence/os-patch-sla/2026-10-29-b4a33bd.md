# os-patch-sla spec §1 targets are environment groups; `vm-target test --spec` resolves hosts on one VM (2026-10-29)

Covers candidate `b4a33bd` on top of `main` `540f736f` (issue #174).

- Spec §1 listed `test-vm` (group `all`), `staging`, `prod`. `pilot verify` treats a targets table with any `all`/empty group row as literal hostnames, so on a single `vm-target` VM it failed with `spec targets contains host "test-vm" that is absent from inventory`; giving the VM both the `staging` and `prod` aliases is rejected by the playbook's stage cross-check (AGENTS §4.3).
- The candidate chooses AGENTS §2.1 option B: §1 is now three environment groups (`sandbox`, `staging`, `prod`), resolved as the group pattern `prod:sandbox:staging` against the inventory passed with `-i`. Checklist rows C1–C8, every Expected value, the playbook and the stage gates are unchanged. The spec documents one disposable VM per stage (`vm-target up --hosts <stage>`), and that staging/prod runs need `-e target_group=<stage>` (play vars set `target_group: sandbox`, so the `hosts:` default never applies).

## Why C1, C2 and C4 fail (not caused or changed here)

- **C1** counts the `Listing...` header line of `apt list --upgradable`, so it can never print `0` (observed in the #167 evidence on a fully patched host: `1`). On the fresh image it printed 191 lines.
- **C2** counts upgradable `security` lines (139 on the fresh image). Step 3 of the playbook passes `--non-interactive`, which Ubuntu 24.04's `unattended-upgrade` does not have, so it has never installed updates (also recorded in the #167 evidence).
- **C4** (`find /var/log/apt/history.log -mtime -90`) fails because the image's `history.log` is older than 90 days.

No Expected value was relaxed to make a run pass (AGENTS §0.2).

## Follow-ups (not in this change)

- The header comments of `playbooks/apply/os-patch-sla-apply.yml` still show staging/prod runs with only `-e patch_stage=…`; those commands match 0 hosts without `-e target_group=<stage>`. The spec's SOP and §1 now show the working commands.
- C1 header-line counting, Step 3's `--non-interactive` flag and the fresh-image C2/C4 state are the pre-existing gaps above; each needs its own decision and test.
