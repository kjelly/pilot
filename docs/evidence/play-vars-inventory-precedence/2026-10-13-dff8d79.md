# Play vars no longer shadow inventory inputs — candidate `dff8d79` (2026-10-13)

Scope: 15 apply playbooks declared, in a play's `vars:`, 60 variables that operators set in inventory (45 contract `groupVars`, 15 keys of `group_vars/<role>.example.yml`). Play vars outrank `group_vars`/`host_vars`, so the operator's value was replaced by the play's default while `pilot deploy`'s preflight read the inventory value. The candidate defaults each of them in an always-tagged `set_fact` after the stage gates (`x: "{{ x | default(<old value>) }}"`); the defaults are unchanged.
