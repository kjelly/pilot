## Tests

- `TestRegression_PrivateCcacheOpenLeavesOtherUsersCaches` runs the open and close task files through Ansible on localhost. A root-owned day-old cache sits in a root-owned sticky directory, created with passwordless sudo; when the test runs as root, the file belongs to nobody instead. The test checks that the run succeeds and the file stays. On the open task of `85bc194` it fails with the same `Unlinking failed: [Errno 1] Operation not permitted` as run 9. The directory must not belong to the test user: the owner of a sticky directory may unlink anything in it, which hid the failure in a first draft of the test.
- `TestRegression_PrivateCcacheOpenCleansOnlyItsOwnStaleCaches` checks that a day-old cache of the same user is removed, while a younger one and a day-old file that does not match `pilot-krb5cc-*` are kept. It also checks that the new cache is a `pilot-krb5cc-*` file, mode 0600, owned by the test user, named in `pilot_krb5ccname`, and gone after close.
- `TestRegression_KinitUsesAPrivateCredentialCache` and `TestKinitScanClassifiesSites` pass unchanged.
