## sudo in the sims

The sims' `sudo -n` step depends on the client's SSSD sudo cache, which picks up a new FreeIPA sudo rule only after its refresh interval. Before that refresh, sudo asks for a password. The private-cache kinit and the SSH login, which this PR changes, passed on every attempt; the `sudo` result changed only with time. `2026-10-15-c328aa6.md` records the same behaviour.
