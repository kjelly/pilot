# FreeIPA realm replacement: a new server that keeps the old server's FQDN — candidate `dd69a2d` (2026-10-13)

Scope: the review of #53 (2026-10-13) found that the new server's pin could be deleted. The playbook wrote it first, before the uninstall. When the new server keeps the old server's FQDN, and the client has freeipa-client's `PILOT FREEIPA SERVER POOL` block, that pin rewrote the line inside the block. The removal of the old block then deleted it, and the enrollment had no pin for the new server.

Two commits on the PR branch, after a merge of `origin/main` (`db10268`):
1. `31fd876` writes the new server's pin after the old pool block and the other old pins are removed, right before the enrollment, and matches the FQDN in any case.
2. `dd69a2d` also removes, after the uninstall, the Kerberos snippet SSSD wrote for the old domain. The first candidate's VM run found it (see "Runs").

## Regression tests

`TestRegression_RealmReplacementRemovesOldServerPins` now runs the new server's pin together with the removal tasks, on localhost, each case twice. Besides the exact `/etc/hosts`, it checks which address the new server's FQDN resolves to: the first line naming it, in any case, as glibc's files source does. New cases:
- the new server keeps the old server's FQDN, inside the pool block;
- the same, as an unmarked line written in another case.

On the old tasks both fail: the name resolves to nothing, or to the old address. `TestRegression_RealmReplacementRemovesOldPinsBetweenUninstallAndEnroll` now requires the pin after the other removals and before the enrollment; it fails on the old order.

`TestRegression_RealmReplacementRemovesTheOldDomainRealmMapping` runs the configuration read and the new removal on localhost:
- the old domain's snippet goes, other snippets stay;
- without a `domain` in `default.conf`, nothing goes;
- a second run changes nothing.

A path without the dot replacement makes it fail. `TestRegression_RealmReplacementRemovesTheOldMappingBeforeEnrolling` locks the task between the uninstall and the enrollment.
