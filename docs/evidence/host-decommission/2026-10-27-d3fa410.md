## Tests

- `TestRegression_IdentityDecommissionDNSQueryStopsOnErrors` and
  `TestRegression_IdentityAbsentHostDNSCheckStopsOnErrors` run the
  playbook's own tasks against a fake `ipa` replaying the captures: record
  exists, record not found, zone not found and DNS not configured pass
  (the record is deleted only when it exists; host-del runs in all four);
  no Kerberos ticket and API unreachable fail at the lookup, before
  `dnsrecord-del`/`host-del`. On `26991860` both error cases pass
  (4 subtests fail); with the allowlist cut to "record not found" the zone
  and not-configured cases fail (4 subtests).
- `TestFreeIPAProvider_HostObjectAndDNSAbsent_OnlyProvenAbsencePasses`
  (selected by HD10's probe) reads the real query stdout: the target's
  own tombstone next to a live record is active_residue; an error printed
  as `HOST_INSPECT` (the pre-fix playbook's httpd-stopped run, and the
  Kerberos message) makes Verify return an error. On `26991860` the
  tombstone case passes and both error cases pass instead of erroring.
- `TestRegression_DNSRecordQueriesFailOnErrors` lists every
  `dnsrecord-show`/`dnsrecord-find` task under `playbooks/` with
  `failed_when: false` and its reason; it flags both lookups on
  `26991860`. Five remain, in freeipa-dns and internal-endpoint.
