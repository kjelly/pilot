### Failures found on the way (earlier candidates)

- `3f40ddf6` (round 2): arm B (`--timeout 5s` with a stalled vault script) did not end pilot; it was still running at 180 s. `exec.CommandContext` killed only `ansible-inventory`; the script and its `sleep` kept pilot's stderr pipe and `Wait` never returned. Fixed in round 3 (`internal/childproc`, spec §2.5). Its arm X was invalid (the external group lacked the `team-` prefix the roster validator requires) and was corrected.
- `84e80dc6` (round 3): arm L2 left the logout's `ssh -W` running after pilot exited while httpd stayed stopped. net/http dials in its own goroutine; `CloseIdleConnections` only cancels a dial in progress, and pilot exited before that goroutine killed the tunnel. On `3f40ddf6` the same arm showed nothing left only because the tunnel was in pilot's process group and got the pty's hangup. Fixed in round 4: `sshdial.Dialer.Close` kills and reaps every ssh the preview started before it returns. That candidate's J2 arm was invalid (a stale `known_hosts` entry failed the hop before the terminal mattered) and was replaced by the unknown-host hop above.
