- Playbook: `playbooks/apply/freeipa-identity-apply.yml` ("Set SSH public keys for users (declarative replace)").
- Test: `internal/spec/freeipa_identity_ssh_keys_regression_test.go`.

- The playbook is `main`'s file with this branch's one change re-applied: an empty `ssh_keys` list sends `--sshpubkey=`, which clears every key. `git diff afeacbd` on the playbook shows only that change (7 insertions, 1 deletion).
- The regression test now also looks for the task inside `block`, `rescue` and `always`, because the task moved into the private-cache block.
