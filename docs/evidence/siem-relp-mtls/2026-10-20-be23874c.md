## Limits and operator boundary

RELP can replay uncertain transactions; duplicates are expected. ACK is not final-file fsync.
Power loss, exhausted queue/disk capacity, messages not yet accepted by client rsyslog, and downstream
Loki durability are outside this transport contract. Each action has a finite 256 MiB disk budget.
mTLS authenticates the peer, while existing payload HOSTNAME routing remains unbound to that identity.
Production issuance/renewal and individual-certificate revocation are operator-managed. The verified
rotation case uses the same CA and DNS identities. Old TCP migration still has its in-flight window.

See [the current runbook](../../runbooks/siem-relp-mtls.md),
[forwarding spec](../../verification/audit-log-forwarding.md), and
[receiver spec](../../verification/log-server.md).
