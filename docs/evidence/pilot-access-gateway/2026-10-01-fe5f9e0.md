# Per-host SSH session recording: AG82 removes the token file the old gateway config named — candidate `fe5f9e0` (2026-10-01)

Scope: one change on top of [`2026-10-01-d7da805.md`](2026-10-01-d7da805.md).
Before per-session tokens, the operator chose the gateway's static bearer
token path (`pilot_access_gateway_recording_session_store_ingest_token_file`)
and `main`'s playbook wrote it into the gateway config as
`recording.session_store_ingest_token_file`. AG82 removed only the default
`/etc/pilot/session-store-ingest-token`, so an upgrade from a gateway that
used another path left the secret on disk while AG82 still passed. `fe5f9e0`
reads the installed config before Step 11 replaces it and removes the file it
names, the default path, and a path the inventory still sets (with a message
to drop the variable). It refuses a relative path, a path with `..`, or a path
that is not a regular file or symlink, before removing anything, and never
lists the config, signing key or keytab the playbook manages.
