## Changes in `46fbc58`

- **First hop.** A first nameserver that answers `id.server CH TXT` with an error rcode is a failed query only at a dns tier address. `DNSArchModel.TierAddrs` gives every tier host's address, plus loopback when the client is itself a tier host. Any other resolver that answers with an error rcode is simply not a tier host. A tier that refuses the client is still reported.
- **FQDNs.** The pool's FQDNs are lower-cased and stripped of the trailing dot once, where the model reads them.
- **Write-rights wording.** The tool description, code comments and runbook §2 now say that only the global DNS configuration's rights are checked. The reader's role must stay the runbook's read-only one.
- **`K/M`.** The deny-list matches `K/M` as a whole.
- **Fixtures.** The live fixture set is now one consistent capture of the topology below, and the tests use its hosts and addresses. `provider.txt`, `tier.txt`, `tier_stopped.txt` and `client.txt` are replaced. The new capture of `auth_role.txt` is byte-identical to the committed file from `f63d490` (the `ipa` output carries no query IDs or timestamps), so that file is unchanged.
  - Normalised for hosts, addresses, query IDs, cookies and TTLs, the new captures equal the old ones line for line.
  - The only differences are the SOA serial, the TTLs, the order of the root NS answers, whitespace, and, in `tier_stopped.txt`, the timestamps and PIDs in unbound-control's error lines.
