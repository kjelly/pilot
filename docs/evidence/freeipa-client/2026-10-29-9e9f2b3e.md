# freeipa-client: KDC name-resolution preflight (revised rule) and classified kinit failures (issue #168)

Issue #168. Spec: `docs/verification/freeipa-client.md` (v1.13). Playbook: `playbooks/apply/freeipa-client-apply.yml` with `playbooks/apply/tasks/freeipa-client-kdc-preflight.yml`, `freeipa-client-kinit-result.yml`, `freeipa-host-annotations.yml` and `freeipa-host-access-policy.yml`. Fixture checked in S7: `internal/spec/testdata/kdc-preflight/libkrb5-kdc-values.json`.

This record covers the revised preflight (after an automated review found two P2s). The deferral rule under test: the preview defers only when it runs with `--check`, the `/etc/hosts` server-pool pin is pending, some KDC name is usable now or at least one configured `kdc` name is a pool member that the pin will make resolvable, and the admin endpoint is resolvable or a pool member. A host whose every configured KDC is outside the pool still fails the preview. The `kdc` value is parsed like libkrb5 (quoted strings, first whitespace token, `https://`, `[v6]`, `host:port`); `master_kdc` is excluded.

|---|---|---|---|---|
